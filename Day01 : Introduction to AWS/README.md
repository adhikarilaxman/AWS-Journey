## Day 01 Notes

## 1. Introduction to Cloud Computing

### What is Cloud?

**Cloud Computing** refers to the delivery of computing resources such as servers, storage, databases, networking, and software over the Internet instead of owning and maintaining physical hardware.

Instead of purchasing servers, organizations **rent resources from a cloud provider** and pay only for what they use.

### Key Features of Cloud Computing:

1. On-demand availability of resources
2. Pay-as-you-use pricing model
3. Scalability (resources can be increased or decreased anytime)
4. Accessibility from anywhere via the Internet

---

## 2. Public Cloud vs Private Cloud

### Public Cloud

Public cloud resources are **owned and managed by third-party cloud providers** and shared among multiple customers.

#### Examples:

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform

#### Characteristics:

* Shared infrastructure
* Lower cost
* High scalability
* Managed by the cloud provider

#### Use Cases:

* Startups
* Web applications
* Development and testing environments

---

### Private Cloud

Private cloud infrastructure is **dedicated to a single organization**.

#### Deployment Options:

* On-premise (within the organization’s data center)
* Hosted by a third party but used exclusively by one organization

#### Examples:

* VMware Private Cloud
* OpenStack

#### Characteristics:

* Full control over infrastructure
* Higher security
* Higher cost
* Limited scalability compared to public cloud

#### Use Cases:

* Banking systems
* Government organizations
* Healthcare applications

---

## 3. Why is Public Cloud So Popular?

Public cloud adoption has increased due to the following reasons:

### 1. Low Cost

* No upfront hardware investment
* No maintenance expenses
* Pay only for consumed resources

### 2. High Scalability

* Resources can be scaled up or down within minutes
* Ideal for variable and unpredictable workloads

### 3. Faster Time to Market

* Applications can be deployed in hours instead of months

### 4. No Infrastructure Management

* Cloud provider handles hardware, power, cooling, and maintenance

### 5. Global Reach

* Data centers available across the world
* Improved performance and availability for global users

---

## 4. Why AWS?

**Amazon Web Services (AWS)** is the world’s leading public cloud platform.

### Reasons for Choosing AWS:

### 1. First Mover Advantage

* Launched in 2006
* Mature, stable, and reliable services

### 2. Largest Service Portfolio

* Compute: EC2
* Storage: S3
* Databases: RDS, DynamoDB
* Networking: VPC
* Additional services for DevOps, AI/ML, and Security

### 3. Global Infrastructure

* Multiple regions and availability zones
* High availability and disaster recovery support

### 4. Strong Security

* Identity and Access Management (IAM)
* Data encryption
* Compliance with standards such as ISO, SOC, and HIPAA

### 5. Huge Community and Job Market

* Extensive documentation
* High demand for AWS-certified professionals

---

## 5. Why Are Some Organizations Moving Back to Private Cloud?

Some organizations are shifting workloads back to private cloud due to:

1. High cloud costs caused by poor resource optimization
2. Data security and regulatory compliance requirements
3. Vendor lock-in concerns
