## Day 09 Notes

## Amazon S3 (Simple Storage Service)

---

### What is Amazon S3?

**Amazon S3 (Simple Storage Service)** is an AWS cloud storage service used to **store and retrieve data as objects** over the internet.

S3 is:

* **Scalable**
* **Highly available**
* **Secure**
* **Cost-effective**

It allows you to store **any amount of data** and access it **from anywhere**.

---

### Key Concepts of S3

* Data is stored as **objects**
* Objects are stored inside **buckets**
* Each object consists of:

  * Data
  * Metadata
  * A unique key (object name)

---

### What Can We Store in S3?

Amazon S3 can store almost any type of file, including:

* Images (JPG, PNG)
* Videos (MP4, MOV)
* Audio files
* Documents (PDF, DOC, XLS)
* Application backups
* Logs and reports
* Static website files (HTML, CSS, JS)
* Database backups
* Big data and analytics files

---

### Important Points

* Maximum object size: **5 TB**
* Designed for **high durability and scalability**
* Suitable for **small files and very large datasets**
* Commonly used for backups, media storage, and static content

---

### Why is S3 Considered a Global Service?

Amazon S3 is a **global service**, but **each bucket is created in a specific AWS region**.

Key points:

* S3 service is available globally
* Data resides in the selected region
* Cross-Region Replication can be enabled if required

---

### Benefits of S3 Being Global

* **High availability**
* **Extremely high durability (99.999999999%)**
* **Easy access from anywhere**
* **Seamless integration with other AWS services**
